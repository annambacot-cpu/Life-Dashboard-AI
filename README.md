# Life Dashboard AI

A personal life operating system for goals, projects, habits, notes, decisions, skills, finances, and weekly reflection.

## Live site

[Open Life Dashboard AI](https://annambacot-cpu.github.io/Life-Dashboard-AI/)

The dashboard saves changes in the browser on the device where it is used. No personal dashboard data is committed to this public repository.

## Features

- Daily Life AI briefing and focus recommendations
- Editable task list and goal progress
- Project OS with next actions
- Habit experiment lab
- Notes and personal knowledge search
- Decision journal and confidence tracking
- Skill growth with evidence
- Calendar and finance views
- Weekly reflection

## Development

Requires Node.js 22 or later and pnpm.

```bash
pnpm install
pnpm run dev
pnpm run build:pages
```

The live site is served from the dedicated `gh-pages` deployment branch.
